# Website Backgrounds

This directory contains background images and textures approved for use across AT Medical web properties.

## Contents

Assets in this directory may include:

- Section background images for use behind content blocks
- Subtle textures and pattern overlays
- Gradient background files
- Full-page background images for landing pages and campaign pages

## Usage Guidelines

- Use only backgrounds that are consistent with the AT Medical visual identity.
- Ensure that any text or content placed over backgrounds maintains sufficient colour contrast and readability (WCAG AA compliance recommended).
- Optimise background images for web delivery — use appropriate compression and consider serving responsive image sizes.
- Do not use web backgrounds for print without obtaining a high-resolution print-quality version.
