# Website UI Elements

This directory contains branded user interface components, graphical elements and interface assets for use in AT Medical web properties.

## Contents

Assets in this directory may include:

- Branded button styles and call-to-action graphics
- Dividers, rules and decorative separators
- Badge and label graphics
- Progress indicators and step graphics
- Branded form element styles
- Icon sets designed for web interface use
- Illustration assets used within the interface layout

## Usage Guidelines

- UI elements must be used in accordance with the AT Medical brand guidelines and design system.
- Do not modify the colour, shape or proportion of UI components.
- Ensure that interactive elements (buttons, links) maintain sufficient colour contrast for accessibility.
- Refer to the brand guidelines for spacing and layout rules around UI components.
- When integrating these assets into code, use appropriate semantic HTML and accessibility attributes.
