# Website Headers

This directory contains branded header images and hero graphics for use on AT Medical web properties.

## Contents

Assets in this directory may include:

- Full-width hero images for homepage and landing pages
- Section header images for product and service pages
- Campaign hero graphics
- Background images used behind navigation headers

## Usage Guidelines

- Use assets at their native resolution to avoid quality degradation.
- Ensure text overlaid on header images maintains sufficient contrast and readability.
- Optimise file sizes for web delivery (compress without visible quality loss) before deployment.
- Do not use header images in print contexts without obtaining a print-quality version.
- Do not alter the composition or branding elements within the header graphics.
