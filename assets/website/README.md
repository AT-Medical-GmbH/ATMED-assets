# Website Assets

This directory contains official AT Medical brand assets for use across AT Medical web properties, including the corporate website, product platforms and landing pages.

## Structure

| Subdirectory | Contents |
|---|---|
| `headers/` | Header images and hero graphics for web pages |
| `footers/` | Footer graphics and branding elements |
| `backgrounds/` | Background images and textures for web layouts |
| `ui-elements/` | Branded UI components, buttons, dividers and interface graphics |

## Usage Guidelines

- Use only assets from this directory for AT Medical web properties.
- Assets must be used at their intended dimensions and must not be stretched or distorted.
- Ensure assets are exported at appropriate resolutions for web (72–96 dpi) and that file sizes are optimised for performance.
- Do not use website assets in print contexts without obtaining a print-quality version from the design team.
