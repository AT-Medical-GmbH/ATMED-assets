# Website Footers

This directory contains branded footer graphics and branding elements for use on AT Medical web properties.

## Contents

Assets in this directory may include:

- Footer background images and textures
- Footer logo lockup graphics
- Divider and separator graphics used above the footer area
- Footer icon sets and social media link icons

## Usage Guidelines

- Use footer graphics consistently across all pages of the same web property.
- Do not alter the logo or wordmark elements within footer graphics.
- Ensure footer graphics are exported at the correct resolution for web delivery.
- Optimise file sizes for performance before deployment.
