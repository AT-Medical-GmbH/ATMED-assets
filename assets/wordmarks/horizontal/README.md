# Wordmarks — Horizontal Layout

This directory contains official AT Medical wordmarks arranged in a horizontal (landscape) layout.

## About Horizontal Wordmarks

Horizontal wordmarks position the logo symbol and text side by side, making them well suited to wide-format applications such as:

- Website navigation bars and headers
- Email signature blocks
- Horizontal banner formats
- Document headers and footers
- Presentation title areas with wide aspect ratios

## Usage Guidelines

- Use the horizontal wordmark when the available space is wider than it is tall.
- Do not stack or reflow the horizontal wordmark into a vertical arrangement — use the `vertical/` variants instead.
- Maintain the required clear space around the wordmark as defined in the brand guidelines.
- Do not alter the proportions, spacing or colour of the wordmark.
