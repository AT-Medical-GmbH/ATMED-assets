# Wordmarks — Vertical Layout

This directory contains official AT Medical wordmarks arranged in a vertical (stacked or portrait) layout.

## About Vertical Wordmarks

Vertical wordmarks position the logo symbol above the text in a stacked arrangement, making them well suited to applications where a square or portrait-oriented space is available, such as:

- Social media profile images
- App icons and mobile interfaces
- Square format print materials (e.g. business cards, stickers)
- Narrow sidebar areas
- Square thumbnails and avatars

## Usage Guidelines

- Use the vertical wordmark when the available space is approximately square or portrait-oriented.
- Do not use the vertical wordmark in wide-format contexts where a horizontal layout is available — use the `horizontal/` variants instead.
- Maintain the required clear space around the wordmark as defined in the brand guidelines.
- Do not alter the proportions, spacing or colour of the wordmark.
