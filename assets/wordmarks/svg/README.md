# Wordmarks — SVG Format

This directory contains official AT Medical wordmarks in Scalable Vector Graphics (SVG) format.

## About SVG Wordmarks

SVG is the preferred format for wordmarks, providing perfect scalability for both digital and print applications. Use SVG wordmarks for:

- Website headers and navigation
- Print materials at any scale
- Design source files
- High-resolution digital applications

## Usage Guidelines

- Do not convert SVG wordmarks to raster formats unless necessary — use the `png/` subdirectory for pre-exported raster versions.
- Do not modify the typeface, letter spacing, weight or colour within these files.
- Do not embed the wordmark SVG in a way that allows its internal elements to be edited by end users.
