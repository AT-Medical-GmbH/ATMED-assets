# Wordmarks

This directory contains the official AT Medical wordmarks — text-based representations of the AT Medical brand name — in all approved layouts and file formats.

## Structure

| Subdirectory | Contents |
|---|---|
| `svg/` | Scalable Vector Graphics — preferred format for print and high-resolution digital use |
| `png/` | Portable Network Graphics — raster format for general digital use |
| `horizontal/` | Wordmarks arranged in a horizontal (landscape) layout |
| `vertical/` | Wordmarks arranged in a vertical (stacked/portrait) layout |

## Usage Guidelines

- Use the horizontal layout when horizontal space is available (e.g. navigation bars, headers).
- Use the vertical layout when the application area is square or portrait-oriented.
- Do not alter the typeface, letter spacing, weight or colour of the wordmark.
- Wordmarks must not be combined with decorative elements that obscure or alter the text.
- Always source files from this repository to ensure you are using the most current approved version.
