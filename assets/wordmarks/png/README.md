# Wordmarks — PNG Format

This directory contains official AT Medical wordmarks in Portable Network Graphics (PNG) format.

## About PNG Wordmarks

PNG wordmarks are pre-exported raster versions for use in digital contexts where SVG is not supported. Use PNG wordmarks for:

- Email clients and email signatures
- Content management systems that do not support SVG
- Social media uploads
- Digital documents and presentations

## Usage Guidelines

- Use the highest resolution PNG available for the intended context.
- Do not upscale PNG wordmarks beyond their native exported resolution.
- For print or large-format applications, use the SVG variants instead.
- Do not alter the colour, background or composition of these files.
