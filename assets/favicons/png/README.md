# Favicons — PNG Format

This directory contains official AT Medical favicons in PNG format at various resolutions.

## About PNG Favicons

PNG favicons provide higher quality rendering on modern browsers and devices compared to the ICO format. Standard PNG favicon sizes include:

- 16×16 px — standard browser tab icon
- 32×32 px — Windows taskbar icon
- 96×96 px — Google TV and Android
- 192×192 px — Android Chrome
- 512×512 px — Progressive Web App (PWA) splash screen

## Usage Guidelines

- Reference PNG favicons in HTML using:
  ```html
  <link rel="icon" type="image/png" sizes="32x32" href="/favicons/png/favicon-32x32.png">
  <link rel="icon" type="image/png" sizes="16x16" href="/favicons/png/favicon-16x16.png">
  ```
- Use alongside ICO and Apple touch icon variants for full cross-browser and cross-device support.
- Do not upscale small PNG favicons for use at larger sizes — use the appropriate pre-exported resolution.
