# Favicons

This directory contains favicon assets for use across AT Medical web properties. Favicons are the small icons displayed in browser tabs, bookmarks and mobile home screens.

## Structure

| Subdirectory | Contents |
|---|---|
| `ico/` | ICO format favicons for broad browser compatibility |
| `png/` | PNG format favicons at various resolutions |
| `apple-touch-icon/` | Apple touch icons for iOS and iPadOS home screen bookmarks |

## Usage Guidelines

- Always include all favicon variants when deploying a web property to ensure compatibility across all browsers and devices.
- Reference favicons using the appropriate HTML `<link>` tags in the `<head>` of each page.
- Do not use custom or unbranded favicons on official AT Medical web properties.
- Ensure favicons are consistent with the current approved logo — if the logo is updated, favicons must also be updated accordingly.
