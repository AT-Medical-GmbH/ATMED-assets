# Apple Touch Icons

This directory contains official AT Medical Apple touch icons for use on iOS and iPadOS devices.

## About Apple Touch Icons

Apple touch icons are displayed when a user adds an AT Medical web page to their iOS or iPadOS home screen. They serve as the app-like icon for the bookmarked site. The standard recommended size is:

- 180×180 px — recommended for iPhone and iPad (retina displays)

Older devices may use:
- 152×152 px — iPad (non-retina)
- 120×120 px — iPhone (non-retina)

## Usage Guidelines

- Reference the Apple touch icon in HTML using:
  ```html
  <link rel="apple-touch-icon" sizes="180x180" href="/favicons/apple-touch-icon/apple-touch-icon.png">
  ```
- Ensure the icon does not have a transparent background, as iOS will apply a white background by default.
- The icon should feature the AT Medical logo or symbol clearly visible at small sizes.
