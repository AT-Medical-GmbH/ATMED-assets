# Favicons — ICO Format

This directory contains official AT Medical favicons in ICO format.

## About ICO Favicons

The ICO format is a legacy container format that can embed multiple resolutions in a single file. It is the most widely supported favicon format, ensuring compatibility with older browsers and Internet Explorer. A standard ICO favicon typically contains the following sizes:

- 16×16 px
- 32×32 px
- 48×48 px

## Usage Guidelines

- Reference the ICO favicon in HTML using:
  ```html
  <link rel="icon" type="image/x-icon" href="/favicons/ico/favicon.ico">
  ```
- Place the `favicon.ico` file in the root directory of the web property for automatic detection by browsers.
- Use alongside PNG and Apple touch icon variants for full cross-browser and cross-device support.
