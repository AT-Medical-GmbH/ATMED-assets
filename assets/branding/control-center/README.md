**Verwendungsregel:** Die Identitätsfarben kennzeichnen ausschließlich das
jeweilige Center (Navigation, Kachel-Chips). Zustände (OK/Warnung/Kritisch)
verwenden immer die feste Status-Palette mit Punkt + Textlabel — Identität
und Status dürfen sich nie farblich vermischen (Rot=System ≠ Rot=Kritisch).
