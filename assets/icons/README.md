# Icons

This directory contains standalone AT Medical brand icons and pictograms used across digital products, documentation and communications.

## Contents

Brand icons are compact visual symbols that represent AT Medical products, services or concepts. They are distinct from the primary logo and are used to complement, not replace, the AT Medical logo or wordmark.

Icons in this directory may include:

- Application icons
- Feature and function pictograms
- Navigation and UI icons in the AT Medical visual style
- Category and discipline icons used in educational and clinical contexts

## Usage Guidelines

- Use icons only in the sizes and colour variants provided.
- Do not recolour, distort or combine icons with other graphic elements in ways not specified by the brand guidelines.
- Icons must not be used as a substitute for the AT Medical logo or wordmark.
- Refer to the official brand guidelines for minimum size requirements and spacing rules.
