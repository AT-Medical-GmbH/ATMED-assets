# Social Media Assets

This directory contains AT Medical brand assets formatted for use on social media platforms. All assets are sized and optimised according to the platform-specific requirements current at the time of creation.

## Structure

| Subdirectory | Contents |
|---|---|
| `linkedin/` | Profile images and cover photos for AT Medical LinkedIn presence |
| `instagram/` | Profile images and post graphics for AT Medical Instagram presence |
| `banners/` | General-purpose banners suitable for use across multiple social media platforms |
| `thumbnails/` | Video and content thumbnails for use on social and video platforms |

## Usage Guidelines

- Use only the assets from the relevant platform subdirectory to ensure correct dimensions and aspect ratios.
- Do not modify the composition, text or branding elements within these assets.
- Ensure that any use of social media assets complies with the terms of service of the relevant platform.
- If updated platform specifications require resizing, submit a pull request rather than independently modifying existing files.
