# Instagram Assets

This directory contains official AT Medical brand assets formatted for use on Instagram.

## Contents

Assets in this directory are sized and optimised for Instagram platform requirements and may include:

- Instagram profile image
- Square post graphics
- Story and Reel graphics (9:16 vertical format)
- Highlight cover icons

## Usage Guidelines

- Use assets only for official AT Medical Instagram properties.
- Do not alter the layout, colour scheme or branding elements.
- Ensure assets are uploaded at the correct resolution specified by the Instagram platform requirements.
- Maintain consistent visual identity by using only approved assets and colour combinations.
