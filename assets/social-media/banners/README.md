# Social Media Banners

This directory contains general-purpose branded banners for use across multiple social media platforms.

## Contents

Banners in this directory are designed for broad social media use and may include:

- Campaign banners for product launches or announcements
- Event promotion banners
- General AT Medical brand awareness banners
- Seasonal or thematic banner variants

## Usage Guidelines

- Select the appropriate banner size for the target platform.
- Do not alter the text, layout or branding elements within the banner.
- Banners must only be used in contexts consistent with the AT Medical brand identity.
- If a specific platform size is not available, submit a contribution request rather than resizing existing assets independently.
