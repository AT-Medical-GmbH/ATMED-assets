# Assets

This directory is the root of all official AT Medical brand assets. It contains structured subdirectories for every category of visual identity resource used across the AT Medical ecosystem.

## Directory Overview

| Directory | Contents |
|---|---|
| `logos/` | Official AT Medical logos in all approved variants and formats |
| `wordmarks/` | Text-based AT Medical wordmarks in all approved layouts |
| `icons/` | Standalone brand icons and pictograms |
| `illustrations/` | Custom illustrations and decorative graphics |
| `social-media/` | Assets formatted for social media platforms |
| `presentations/` | Slide deck templates and presentation assets |
| `documents/` | Branded document templates and stationery |
| `website/` | Assets used across AT Medical web properties |
| `favicons/` | Favicon assets for web browsers and mobile devices |
| `brand-guidelines/` | Official AT Medical brand guidelines and documentation |
