# Logos — Light Mode Variants

This directory contains official AT Medical logos optimised for use on light or white backgrounds.

## About Light Mode Logos

Light mode logo variants are designed to maintain visual clarity and brand consistency when placed on light backgrounds. Use these variants for:

- Light-themed websites and applications
- White or light-coloured backgrounds in presentations and documents
- Light-mode user interfaces
- Standard print materials on white or light paper

## Usage Guidelines

- Use light mode logos exclusively on backgrounds that are light in tone (e.g. white, light grey, cream).
- Do not use light mode logos on dark or black backgrounds — use the `dark-mode/` variants instead.
- Do not alter the colour, transparency or composition of these assets.
- Ensure sufficient contrast between the logo and its background at all times.
