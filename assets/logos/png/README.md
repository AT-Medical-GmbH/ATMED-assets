# Logos — PNG Format

This directory contains official AT Medical logos in Portable Network Graphics (PNG) format.

## About PNG Logos

PNG is a raster format suitable for digital use where a vector format is not supported or required. PNG logos in this directory are exported at high resolution to support a range of digital use cases including:

- Web pages and web applications
- Social media profile images and posts
- Email signatures and correspondence
- Digital documents and presentations

## File Naming and Resolution

Logo files should follow a consistent naming convention that indicates the variant and resolution, for example:

```
at-medical-logo-primary-1024px.png
at-medical-logo-primary-512px.png
at-medical-logo-white-512px.png
```

## Usage Guidelines

- Use the highest resolution PNG available for the intended context.
- Do not upscale PNG logos beyond their exported resolution.
- For print or large-format use, use the SVG variants instead.
- Do not modify colours, transparency or composition of these files.
