# Logos

This directory contains the official AT Medical logos in all approved variants and file formats.

## Structure

| Subdirectory | Contents |
|---|---|
| `svg/` | Scalable Vector Graphics — preferred format for print and high-resolution digital use |
| `png/` | Portable Network Graphics — raster format for general digital use |
| `monochrome/` | Single-colour logo variants for use on restricted-colour backgrounds |
| `dark-mode/` | Logo variants optimised for dark or black backgrounds |
| `light-mode/` | Logo variants optimised for light or white backgrounds |

## Usage Guidelines

- Always use the appropriate variant for the background colour and context.
- Do not alter logo proportions, colours or spacing.
- Maintain the required clear space around the logo as defined in the official brand guidelines.
- Use SVG format wherever possible to ensure sharpness at all sizes.
- For digital use at fixed sizes, use the PNG variants.
