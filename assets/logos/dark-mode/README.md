# Logos — Dark Mode Variants

This directory contains official AT Medical logos optimised for use on dark or black backgrounds.

## About Dark Mode Logos

Dark mode logo variants are designed to maintain visual clarity and brand consistency when placed on dark backgrounds. Use these variants for:

- Dark-themed websites and applications
- Dark backgrounds in presentations
- Dark-mode user interfaces
- Dark social media post backgrounds or cover images

## Usage Guidelines

- Use dark mode logos exclusively on backgrounds that are dark in tone (e.g. black, very dark grey, deep navy).
- Do not use dark mode logos on light or white backgrounds — use the `light-mode/` variants instead.
- Do not alter the colour, transparency or composition of these assets.
- Ensure sufficient contrast between the logo and its background at all times.
