# Logos — SVG Format

This directory contains official AT Medical logos in Scalable Vector Graphics (SVG) format.

## About SVG Logos

SVG is a vector-based format that scales to any size without loss of quality. SVG logos are the preferred format for:

- Print materials at any scale
- High-resolution digital displays (Retina / HiDPI screens)
- Websites where scalability is required
- Design files and source artwork

## Usage Guidelines

- SVG logos are the master format — use them wherever possible.
- Do not open and re-save SVG files in applications that may alter path data or embed raster images.
- Always embed fonts or convert text to outlines before sharing SVG files externally.
- Do not modify the paths, colours or structure of these files.
